# AquaKotik — Web (GitHub Pages)

Эта папка — **«мессенджер без своего сервера»**: фронтенд — обычный статический
HTML/JS, который лежит на **GitHub Pages** (бесплатно, адрес вида
`имя.github.io/aquakotik/`), а общие данные (сообщения, пользователи, звёзды,
опросы, анонсы) живут в бесплатном **Firebase Realtime Database** (Google).

> «Без сервера» = **без СВОЕГО** сервера. Данные синхронизируются через hosted-
> базу Firebase, поэтому сообщения реально ходят между разными людьми и
> устройствами — как у друга, но на своём `github.io`.

Когда этот файл открывается через локальный Node-сервер (`node server.js`),
веб-режим **не** включается — работает всё как раньше.

## Шаг 1. Создать бесплатный Firebase (≈ 3 минуты)

1. Открой <https://console.firebase.google.com> (нужен аккаунт Google).
2. **Добавить проект** → придумай имя (например, `aquakotik`) → дальше по
   шагам (Google Analytics можно выключить).
3. На странице проекта: значок ⚙️ **Настройки проекта → Общие → Ваши приложения**.
4. Нажми иконку **`</>`** (веб) → придумай псевдоним → **Зарегистрировать**.
5. Firebase покажет объект `firebaseConfig`. Скопируй из него:
   - `apiKey`
   - `authDomain`
   - `databaseURL`  (вид `https://твой-проект-default-rtdb.firebaseio.com`)
   - `projectId`
6. Открой в этой папке файл **`firebase-config.js`** и вставь эти значения
   (пока `apiKey: ""` — веб-режим выключен; вставил `apiKey` — включён).

### Включить Realtime Database и правила доступа

1. В проекте слева: **Realtime Database → Создать базу данных** → выбери регион
   → «Создать».
2. Вкладка **Правила** → вставь (для старта — доступ разрешён, см. предупреждение
   внизу):
   ```json
   {
     "rules": {
       "aquakotik": {
         ".read": true,
         ".write": true
       }
     }
   }
   ```
3. **Опубликовать**.

> ⚠️ **Важно про безопасность.** Правило выше открыто «на всех» — так проще для
> старта, но любой с адресом базы сможет читать/писать. Для своего мессенджера
> между друзьями этого обычно достаточно. Когда захочешь надёжнее — добавь
> Firebase Authentication и перекрой правила (могу помочь отдельно).

## Шаг 2. Выложить на GitHub Pages (≈ 3 минуты)

Нужен аккаунт <https://github.com>. Есть два способа.

### Способ А. Через сайт GitHub (без git)
1. На GitHub: **New repository** → имя, например, `aquakotik` → **Public** → создать.
2. В репозитории: **Add file → Upload files** → перетащи **всё содержимое этой
   папки** (`index.html`, `ak-web-backend.js`, `firebase-config.js`,
   `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`).
3. **Commit changes**.
4. **Settings → Pages → Build and deployment → Source: «Deploy from a branch»**,
   ветка `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты GitHub напишет адрес:
   `https://ТВОЁ-ИМЯ.github.io/aquakotik/`  — это и есть твой мессенджер.

### Способ Б. Через git (если установлен)
Открой командную строку **в этой папке** и выполни:
```
git init
git add .
git commit -m "AquaKotik web"
git branch -M main
git remote add origin https://github.com/ТВОЁ-ИМЯ/aquakotik.git
git push -u origin main
```
Дальше включи Pages как в шаге 4 способа А.

> Либо просто запусти **`PUBLISH-GITHUB.bat`** рядом — он проведёт по git-шагам
> и откроет страницу Pages в браузере.

1. Открой `https://ТВОЁ-ИМЯ.github.io/aquakotik/` **на телефоне**.

3. На каждом: зарегистрируйся (имя, email, пароль) → получи свой код вида `AKxxxxxx`.
4. Добавь друга по коду (чаты → «+» → код друга) → напиши сообщение.

## Что работает в веб-версии
Сообщения 1‑на‑1 · контакты по коду · онлайн/печатают · профиль (имя, аватар,
шрифт, пол) · звёзды и косметика · подарки звёздами · группы · боты ·
анонсы и опросы от админа · сезон/скидка от админа.

## Чего нет в веб-версии
- Скачивание Windows-установщика (`.exe`) — это только для локальной сборки.
- Офлайн-режим частичный (оболочка кэшируется; данные — онлайн через Firebase).

## Бесплатно?
Да: **GitHub Pages** (бесплатно) + **Firebase Spark** (бесплатный тариф: 1 ГБ
база, 10 000 загрузок/день, 50 000 чтений/день). Для мессенджера между
друзьями этого хватает с запасом.
